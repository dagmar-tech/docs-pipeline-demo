# Mistakes log

Every mistake a reviewer catches is written down here, with the rule it led to.
This is how quality improves over time instead of the same errors coming back.

The entries below are **sample entries for the demo**, not real incidents.

| Date | What went wrong | Caught by | Rule added or changed |
|---|---|---|---|
| 2026-11-04 | Draft kept the old menu name in a screenshot caption. | Reviewer | Rule 4: no deprecated terms, including captions. |
| 2026-11-05 | Draft stated a 10-minute limit that appears nowhere in the facts. | Drift check | Rule 3: state a number only if it is in `limits`. |
| 2026-11-06 | Draft added a "Pro plan only" note the release did not mention. | Reviewer | Rule 5: do not describe things that are not in the release changes. |
| 2026-11-07 | A new page linked to a page that does not exist yet. | Drift check | Rule 10: link only to pages that exist. |
