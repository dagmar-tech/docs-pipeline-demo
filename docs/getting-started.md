# Getting started with Acme Voice

Acme Voice is a cloud phone system for small teams. This page covers the three
things most new customers set up first.

## 1. Set up call routing

Open **Routing rules** in the main menu and create your first rule.
See [Set up call routing](call-routing.md) for the full steps.

## 2. Turn on voicemail

Open **Voicemail** and choose a greeting. See [Voicemail](voicemail.md).

## 3. Check how your team is doing

Open **Insights** to see call volume per agent and the missed-call trend.
