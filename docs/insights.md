# Insights dashboard

Insights (formerly Reports tab) shows how your team handles calls.

## Open the dashboard

1. Open **Insights** in the main menu.
2. Choose a date range.

## What you can see

- Call volume per agent.
- A missed-call trend over the selected period.

See [Getting started](getting-started.md) for the other first-day setup steps.
